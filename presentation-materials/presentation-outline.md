# Presentation Outline

## Title

**The Rise of AI Coding Agents in 2026: Helpful Learning Tools or a Risk of Overdependence?**

## Presentation Format

- Pre-recorded video with PowerPoint slides
- Target length: 2 minutes and 50 seconds
- Students will use their own voices
- No AI-generated voices will be used

## Planned Structure

### 1. Introduction — 0:00–0:15

- Introduce the topic and group members.
- Explain that AI coding tools are developing into agents that can complete multistep programming tasks.

### 2. Current Event and Definition — 0:15–0:45

- Mention the 2026 development of tools such as OpenAI Codex and GitHub Copilot Agent.
- Explain the difference between a basic code-suggestion tool and an AI coding agent.
- An AI coding agent can inspect files, propose changes, run commands, and test code.

### 3. Benefits — 0:45–1:15

- Explains unfamiliar code.
- Helps identify and correct errors.
- Saves time on repetitive tasks.
- Supports beginners with examples and personalized assistance.

### 4. Risks — 1:15–1:50

- Generated code may contain errors or security problems.
- Students may copy code without understanding it.
- Overdependence may weaken independent problem-solving.
- Users must consider privacy and academic-integrity rules.

### 5. Balanced Use and Simple Example — 1:50–2:20

- Show or describe a short AI coding-assistant example.
- Explain that users should test the code and understand every important part.
- Emphasize that AI should support human judgment, not replace it.

### 6. Conclusion — 2:20–2:35

- AI coding agents can improve productivity and support learning.
- Their value depends on responsible use, human review, and continued independent practice.

### 7. Discussion Question — 2:35–2:50

**If AI coding agents help students finish programs faster but may reduce independent problem-solving, how should schools decide what level of AI assistance is acceptable?**

## Preliminary Speaking Roles

- Student 1: Introduction, current event, and benefits
- Student 2: Risks, balanced use, conclusion, and discussion question

Roles may be adjusted when the second group member begins contributing.
