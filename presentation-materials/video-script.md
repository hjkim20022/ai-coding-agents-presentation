## HeeJung Kim — Slides 1 and 2

Hello, everyone. Our topic is “The Rise of AI Coding Agents in 2026: Helpful Tools or a Risk of Overdependence?”

AI coding assistants originally focused mainly on suggesting small pieces of code. However, they are now becoming agents that can perform multistep programming tasks.

OpenAI introduced a Codex research preview in 2025. In February 2026, it introduced the Codex desktop app and expanded it to Windows in March. In June 2026, GitHub also integrated Copilot Agent into JetBrains AI Assistant.

These agents can inspect project files, propose changes, run commands, test code, and improve their work. This development could change how students and professional programmers create software.

## Arif Azmi — Slides 3 and 5

AI coding agents offer several benefits. First, they can explain unfamiliar code in beginner-friendly language. Second, they can help identify errors and suggest possible corrections. Third, they can save time by handling repetitive work and creating quick prototypes.

For example, a student might ask an AI agent to write a Python function that calculates an average. The agent may generate code using the sum and length of a list.

However, if the list is empty, that code will fail. The student must test the function, recognize the problem, and add an empty-list check. This example shows that AI can provide a useful starting point, but the user is still responsible for understanding and verifying the result.

## Eren Cam — Slides 4, 6, and 7

AI coding agents also create important risks. Generated code may contain errors or security problems. Users could expose private information, and students may become dependent on AI instead of developing independent problem-solving skills. AI use must also follow academic-integrity rules.

The OECD Digital Education Outlook 2026 provides a balanced conclusion. It explains that generative AI can support learning when it follows clear teaching principles. However, completing tasks successfully with AI does not always produce genuine learning.

Therefore, AI should support human thinking rather than replace it. Students should ask for explanations, test the code, practise independently, and ensure they can explain their final work.

Our discussion question is: How should schools decide what level of AI coding assistance is acceptable?
